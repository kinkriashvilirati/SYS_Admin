# SYS Admin — შუალედურისთვის მზადება

საიტი 4 ქვიზის კითხვებით: **ბარათები** (ვიცი / არ ვიცი), **ყველა კითხვა** და **საგამოცდო სიმულაცია** (5 განმარტება + 5 ღია კითხვა + 10 ტესტი).

## ფაილები

| ფაილი | რა არის |
|---|---|
| `index.html` | მთავარი გვერდი (Netlify ამას ხსნის) |
| `styles.css` | დიზაინი |
| `app.js` | ლოგიკა (ბარათები, გამოცდა, შედეგები) |
| `questions.js` | **ყველა კითხვა და პასუხი** — აქ ასწორებ |
| `ქვიზი *.pages` | ორიგინალი ქვიზები (არ შეცვლილა) |

## Netlify-ზე ატვირთვა (2 წუთი)

1. გახსენი **https://app.netlify.com/drop**
2. გადაათრიე მთელი `SYS_Admin` საქაღალდე იმ ველში
3. მიიღებ ბმულს (მაგ. `https://xxxx.netlify.app`) — გაუგზავნე მეგობრებს

(.pages ფაილებიც აიტვირთება — არაფერს აფუჭებს. თუ არ გინდა, ატვირთვამდე გადაიტანე სხვაგან.)

## კითხვის შესწორება / დამატება

გახსენი `questions.js` ნებისმიერ ტექსტურ რედაქტორში:

```js
def(1, 'ტერმინი', 'განმარტება');
open(2, 'კითხვა?', `პასუხი`);
mcq(3, 'კითხვა?', ['ა', 'ბ', 'გ', 'დ'], 2, 'შენიშვნა');   // 2 = გ არის სწორი
```

შეინახე და Netlify-ზე თავიდან ატვირთე.

## მნიშვნელოვანი

- **პასუხები AI-ს დაწერილია** — ქვიზებში პასუხები არ ეწერა. თუ ლექტორის პასუხი სხვაა, შეასწორე `questions.js`-ში.
- სადავო ტესტებს (სადაც ორი ვარიანტიც შეიძლება სწორი იყოს) ახლავს შენიშვნა და ორივე ვარიანტი ითვლება.
- **პროგრესი ინახება ბრაუზერში** — ყველა სტუდენტს თავისი აქვს, ერთმანეთისას ვერ შეცვლიან. სხვა მოწყობილობაზე პროგრესი არ გადადის.
- პრაქტიკული (ლაბის) ნაწილი ბაზაში არ შედის.
